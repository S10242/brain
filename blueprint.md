# Project Blueprint

## Overview

This project is a web application that provides psychological insights and educational content. It includes psychological tests, lectures on various topics, and interactive 3D elements.

## Implemented Features

*   **Psychological Tests:**
    *   Stress Test

*   **Lectures:**
    *   Confirmation Bias
    *   Dopamine
    *   Pavlov's Experiment
